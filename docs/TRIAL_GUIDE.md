# Research Studio: first trial

Allow 10–15 minutes. Use a non-sensitive sample question first, then a real question only after reviewing the mode/provider labels. A configured real provider can receive your input and consume provider quota. Demo outputs and fallback sections are illustrations, not verified market research.

1. Choose one question whose answer would change your next action. Record your current assumption separately.
2. Run once, inspect progress, and use cancel if needed. Check whether the final report is completed, partial or degraded; do not infer success from activity alone.
3. Inspect a source and its date. Standard does not guarantee citation URL verification. Deep is available only when its capability gates pass; do not bypass its disabled/preview state to complete a trial.
4. Export the report and the structured LaunchLens brief. Keep the full report as context. Review imported idea, audience, market, tone and constraints before generating a launch workspace. If automatic handoff is unavailable, use the downloaded JSON with LaunchLens's import control.
5. Keep a local export before leaving. Restore an existing cached session to review it; starting a new run is a separate action and can use quota. Review content before generating a public share.

## Feedback

Send your inviter a redacted description of the task, chosen mode, completed steps, blockers, missing evidence and whether you would use the tool for a second question. Screenshots are optional; remove project secrets, identifiers, recovery links, keys and customer data. For a public reproducible defect use the repository's issue tracker. Do not post full confidential reports.

The first-trial guide is also available as an expandable section on the empty workspace, in English and Chinese. No feedback is automatically collected by that guide. Existing aggregate analytics are documented in [ANALYTICS.md](ANALYTICS.md).

## Maintainer acceptance

Before inviting someone, open the exact PR preview or production version being shared. Check sample start, cancel, completion/fallback labels, report export and brief import into the matching LaunchLens version. Confirm browser history restoration does not start a new run. A local mock run is an interaction check, not a real-provider quality assessment or validation of hosted Redis/QStash recovery.

Use a private session record for consented participant notes; do not commit them here. Record untested steps as untested. Keep participant-provided data separate from synthetic browser fixtures.
